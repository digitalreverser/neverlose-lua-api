# Примеры Lua

[Главная](../README.md) · [Быстрый старт](../docs/getting-started.md) · [Справочник](../docs/reference.md)

| Файл | Назначение |
| --- | --- |
| [01_hello_world.lua](01_hello_world.lua) | Сообщения при загрузке и выгрузке |
| [02_overlay.lua](02_overlay.lua) | Переключатель в меню и плашка на экране |
| [03_menu_events.lua](03_menu_events.lua) | События: открытие меню, загрузка карты, урон |
| [04_createmove.lua](04_createmove.lua) | Чтение команды и состояния локального игрока |
| [05_players_trace.lua](05_players_trace.lua) | Перебор игроков, проекция на экран и трасса по взгляду |
| [06_storage.lua](06_storage.lua) | `database`, `json`, `msgpack`, отложенный вызов |

Скопируй выбранный файл в `C:\neverwin\scripts`, обнови список Extensions и загрузи его. Либо вставь
код в скрипт через встроенный редактор.

Примеры не требуют Allow Insecure. Они подготовлены как минимальные; запуск в игре ещё не проверен.
